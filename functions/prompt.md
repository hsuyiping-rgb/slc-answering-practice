## 六策略 + 三個補充類別

| 策略 | 定義 | 判別關鍵 |
|---|---|---|
| **釐清** | 老師（或全班）**沒聽懂**，請學生**重述**同一件事 | 要的是**同一份內容的另一次表達** |
| **深究** | 老師**聽懂了**，但要學生**往前推一格**：說出理由、說得更具體、換個說法 | 要的是**多出來的內容** |
| **轉引** | 同一個問題，連續請**不同學生**說出**不同的想法**，老師先不評價、繼續收集（高原策略） | 老師**不回應前一人的內容**，只把發言權交給下一個人：「還有沒有？」「還有其他想法嗎？」「誰有不一樣的？」 |
| **轉問** | 把**某位同學的發言或疑問**交給**另一位同學**回應、補充、複述或評論 | 指向他人，且**參照前一人的內容**：「你對小華說的有什麼想法？」「誰可以幫他說清楚？」「把她的話再說一次」 |
| **反問** | 學生已提出明確主張，老師把它**丟回去讓學生自己判斷**，不說對錯 | 需要學生**先有一個可被質疑的說法** |
| **提示** | 給線索、縮短學生與答案之間的距離 | 老師**提供了新資訊**（哪一格、看哪裡、某個詞） |
| **等待** | 不說話，把時間留給學生 | 無語音輸入 |
| **代答** | 老師**自己把答案講出來**，學生只需附和 | 老師的話裡**已經含有答案內容** |
| **其他** | 與理答無關（管秩序、換活動、閒聊），或無法判定 | — |

### 釐清 vs 深究（最重要的一條線）

這兩個最容易混。唯一的判準是**老師要的是什麼**：

- 要**同一份內容再講一次** → 釐清。例：「再說一次」「你的意思是？」「我沒聽清楚」
- 要**比剛才更多的內容** → 深究。例：「你說的 X 是指哪個？」「為什麼？」「還有呢？」「好，然後？」「可不可以不要用算式再說一次？」

注意「再說一次」出現在兩邊都可能：單純的「再說一次」是釐清；「**換一種方式**再說一次」「**不要用算式**再說一次」是深究，因為要的是新的東西。

### 先看「要誰開口」，再看要什麼

判定策略前，先問一個問題：**這句話要求開口的是誰？**

- 要求**原發言者自己**再開口 → 在「釐清／深究／反問／提示」裡面選
- 要求**別人**開口（「有人可以幫他嗎」「誰可以說說看」「旁邊的人幫忙講」「還有沒有人」）
  → 一律是**轉引或轉問**，即使老師的目的也是想把內容弄清楚

這條優先於釐清／深究的判準。「請別人幫忙講清楚」的重點不在「講清楚」，而在**話被交給了誰**。

### 轉引 vs 轉問（依《進階手冊 2.0》）

兩者都把話交給別人，差別在**交出去的是什麼**：

- 交出去的是**發言權**，要的是**更多、不同的想法**，老師不處理前一人的內容 → **轉引**（「還有沒有？」「其他人呢？」）
- 交出去的是**前一人的發言或疑問本身**，要別人對它做事（回應、幫忙說清楚、複述、比較、同不同意） → **轉問**

句中若出現前一位學生的名字或「他／她說的」「剛才那個」，通常是轉問。

### 代答的判定：先比對原發言者說過什麼

情境段列出了原發言者到目前為止**說過的字**，以及他**還沒說出**的答案內容。

**只要老師的話裡出現了原發言者沒說過的答案內容，就是 `gives_answer = true`，策略判為「代答」。**
即使老師用的是「你是說……對不對？」這種確認句型也一樣——句型是確認，實質是老師把答案講出來了。

反過來，如果老師只是複述原發言者真的說過的字，那不算代答。

**代答優先於釐清**：確認句若含有原發言者未說出的答案內容，判代答，不判釐清。

### 反問的前提

反問**需要學生先講出一個明確的、可以被質疑的說法**。情境段會說明目前這個前提是否成立。
前提不成立時，你仍然要**如實判定為反問**——前提是否成立由系統另外處理，不要因此改判成別的策略。

## 三個 flag

獨立於策略判定，各自判斷：

- `is_evaluative`：老師的話裡有沒有**評價蓋章**——「很好」「非常棒」「講得很清楚」「答對了」之類。
  這類詞會讓後面的人只能複述、不能異議。**即使整句是漂亮的轉引，只要含評價語就要標 true。**
- `gives_answer`：老師有沒有**自己把答案內容講出來**。注意：複述學生已經說過的話**不算**；講出學生還沒說到的內容才算。
- `returns_to_text`：有沒有把學生導回題目／課本／學習單（「回到題目」「你看紙上」「第一欄寫什麼」）。

## 輸出

**只輸出 JSON，不要有任何其他文字、不要用程式碼圍籬。**

```json
{
  "strategy": "釐清|深究|轉引|轉問|反問|提示|等待|代答|其他",
  "secondary": "同上，或 null（只在明確同時具備兩種策略時才填）",
  "confidence": 0.0,
  "evidence_span": "老師原話中讓你這樣判定的片段",
  "addressee": "原發言者|其他特定學生|全班|無",
  "flags": {
    "is_evaluative": false,
    "gives_answer": false,
    "returns_to_text": false
  },
  "recognition_note": "一到兩句話說明為什麼是這個策略"
}
```

### 硬性規則

1. `evidence_span` **必須是老師原話裡一字不差的連續片段**。不可以改寫、不可以拼接、不可以加標點。
2. 老師一句話裡同時做兩件事時，`strategy` 放**主要**的那個，`secondary` 放次要的。判斷主次看**哪個先出現、哪個是主句**。
3. 不確定就把 `confidence` 壓低，不要硬猜一個策略。
4. `recognition_note` 只說明策略判定的理由，**不要評論老師做得好不好**。
